# 楽ブレ HP（GitHub Pages用・軽量版）

## GitHubへの配置
1. GitHubリポジトリ `infoversionk-collab/rakubure` を開く
2. リポジトリの公開ルートにある `index.html` を、このフォルダ内の `index.html` に置き換える
3. このフォルダ内の `assets` フォルダも、同じ公開ルートにアップロードする
4. コミット後、数分待って公開サイトを確認する

重要：`index.html` と `assets` フォルダは必ず同じ階層に置いてください。

公開URL：
https://infoversionk-collab.github.io/rakubure/

画像をHTMLに直接埋め込まず、assetsフォルダに分けた構成です。
