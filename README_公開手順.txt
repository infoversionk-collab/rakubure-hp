楽ブレHP 軽量版（料金改定反映）

内容
- index.html：Webサイト本体
- assets/：ロゴと書類サンプル画像

反映した料金
【個人】月額3,300円（税込）／全4種類の書類機能を利用／Squareサブスクリプション購入／請求書払い不可
【法人】3〜9名：3,300円（税込）/名/月、10〜19名：3,000円（税込）/名/月、20名以上：2,700円（税込）/名/月
法人の支払い：Squareサブスクリプション購入、請求書払い対応可
無料トライアル：登録日から30日間
単品販売：なし

GitHub Pagesへの反映
1. ZIPを解凍する
2. リポジトリ https://github.com/infoversionk-collab/rakubure を開く
3. ルートの index.html をこのパッケージの index.html で置き換える
4. assets フォルダも同じ階層にアップロード／置き換える
5. Commit changes を実行する
6. https://infoversionk-collab.github.io/rakubure/ で表示を確認する

注意
- このパッケージを作成しただけで、GitHubへのアップロードや公開反映は完了していません。
- Squareの実際の購入URLはまだページに接続されていません。現在の「無料体験」ボタンは問い合わせ欄へ移動します。公開前に問い合わせ先メールアドレスとSquare購入リンクを設定してください。
- 30日間無料の判定と、無料期間終了後の利用権限・課金連携は、HPの表示だけでは動作しません。楽ブレのアプリ側とSquare側で別途実装・設定が必要です。
