# 楽ブレ HP 公開用ファイル

## 公開方法（GitHub Pages）
既存リポジトリ `infoversionk-collab/rakubure` の公開ルートにある `index.html` を、このパッケージの `index.html` に置き換えてください。

1. GitHubで `infoversionk-collab/rakubure` を開く
2. 公開ルートの `index.html` を置き換える
3. 変更をコミットする
4. 数分待って公開URLを確認する

公開URL：
https://infoversionk-collab.github.io/rakubure/

## 注意
- 画像はHTML内に埋め込まれているため、画像フォルダは不要です。
- 無料トライアルの案内ボタンはありますが、登録・決済処理は別途接続が必要です。
- 公開前に表示確認を行ってください。
